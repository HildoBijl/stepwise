# @step-wise/course-analysis

`@step-wise/course-analysis` combines a resolved course with learner skill-tracking data to determine progress and recommend what to practise next. Callers supply the applicable skill tree and an exercise-availability predicate, so this package does not depend on a concrete skill tree or exercise registry.


## Status

This package initially preserves the course-analysis behavior previously implemented in the Step-Wise frontend. Its API and internal organization will be reviewed before the full documentation is completed.
